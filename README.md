# Zapas

Локальное приложение для macOS: понять давление памяти, найти подходящие вкладки Chrome и устройства Simulator, проверить результат выбранного действия. Проект не обещает универсальную «очистку RAM».

**Статус:** технические прототипы этапа A реализованы. Проверены Swift, IPC и живой сценарий в изолированном Chrome Stable. GUI строки меню — следующий этап B. Живая проверка LLDB отложена пользователем; macOS 14 и сохранение Charles ещё не проверены. Основное название — Zapas; исходный пакет назывался MemoryPilot.

## Разработка

Swift 6, macOS 14+. Данные диагностики остаются на компьютере. Полноценные GUI, CLI и MCP вводятся поэтапно после проверки системных API и интеграций.

```sh
swift build --scratch-path .local/build
swift test --scratch-path .local/test-build
node --test chrome-extension/policy.test.mjs
zapas_bin_dir="$(swift build --scratch-path .local/build --show-bin-path)"
"$zapas_bin_dir/zapas-probe" system --samples 3 --interval 2
```

`ZapasCore` читает Mach/sysctl/libproc и simctl JSON. `zapas-probe` выдаёт экспериментальный JSON/NDJSON с источниками, единицами и причинами недоступности. Точная память вкладок Stable неизвестна: альтернативный MVP — давность активности и наблюдаемый суммарный footprint Chrome. Сумма процессных показателей не равна уникальной физической RAM.

`zapas-native-host` и Manifest V3 расширение проверяют связь и выгрузку только явно выбранных собственных тестовых страниц. Разрешения расширения: `tabs`, `nativeMessaging`; все профили и native manifests локальные. Команд общего завершения процессов, выключения симуляторов или управления Charles нет. Автоматический Chrome-тест запускается только с явным `--run`: см. runbook.
