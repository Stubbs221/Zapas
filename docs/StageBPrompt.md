# Готовое поручение: реализовать этап B

Реализуй **только этап B — оболочка и диагностика Zapas** в текущем корне репозитория `Stubbs221/Zapas`, ветка `main`. Прочитай `AGENTS.md`, `README.md`, `docs/ProjectPlan.md`, `docs/StageA.md`, `docs/StageARunbook.md` и `docs/StageAReport.md`. Сохрани существующие изменения. База A: Swift 6/macOS 14, ZapasCore с Mach/sysctl/libproc, экспериментальные probe/Native Messaging/IPC; прошли 21 Swift-тест, 25 Node-тестов, 13 IPC-тестов и 12 живых проверок Chrome Stable.

Сначала зафиксируй актуальную исходную сборку и оставшуюся квалификацию. Реальное выполнение на macOS 14, physical sleep/wake и синхронное процессное сравнение Activity Monitor ещё не проверены. Живой LLDB отложен пользователем, Charles отсутствовал; это не блокирует независимую системную оболочку. Не считать неизвестную RAM вкладок нулём: приняты activity и наблюдаемый footprint Chrome. Не превращать частичную сумму footprint в уникальную RAM.

Создай нативную macOS `.app` со значком строки меню и компактным русским окном по локальному референсу OpenUsage: системная карточка, список приложений, мини-график за 15 минут, настройки, ошибки/unknown/stale и пустые состояния. Используй MenuBarExtra window style, SwiftUI/AppKit и библиотеку ZapasCore; app работает без Chrome-расширения и Xcode. Запуск при входе — только опция пользователя, выключенная по умолчанию. Подробный сбор вне main actor при открытом окне, лёгкий фон, один coordinator, ограниченный history; сбрасывай swap baseline при sleep/wake notifications. Определи и документируй стабильный read-only CLI JSON v1 вместо автоматической фиксации probe-схемы.

Дай воспроизводимую локальную сборку/упаковку, осмысленные Swift Testing проверки координации и ошибок, проверь видимый UI, доступность и стоимость GUI/фона. Запиши команды, версии, PASS/NOT RUN, фактические бюджеты и ограничения signing/macOS в `docs/StageBReport.md`; обнови README. Скриншоты, реальные измерения, профили и назначения остаются в `.local/`. Перед любыми simulator-действиями повторно проверь полный список и явное назначение Zapas, максимум восемь устройств; чужие не использовать. Для Jira — только существующий Safari при отдельной авторизации.

В B не добавлять пользовательские Chrome-действия, kill/shutdown, управление LLDB/Charles, MCP или автоматические правила. Не расширять разрешения ради непроведённых сценариев. После проверок создай русскоязычный коммит и отправь разрешённые результаты в `main`, не публикуя локальные данные. Заверши отчётом и готовым поручением **реализовать этап C**, сохраняя непроведённые проверки видимыми. Этап C автоматически не начинать.
