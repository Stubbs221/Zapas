Zapas · Chrome

Подключите этот профиль к локальному приложению Zapas.

Три шага подключения

  1. В Zapas откройте Chrome → Подключение и защита → «Установить Native Messaging». Выберите корень Chrome user-data.
  2. Загрузите расширение через chrome://extensions → Режим разработчика → Загрузить распакованное. Установка в Chrome Web Store не выполнена.
  3. Задайте метку профиля и нажмите «Подключить» ниже. Выбор вкладок и preview находятся в Zapas.

Разрешение tabs позволяет видеть названия и домены вкладок. Передаются только их состояние локальному приложению; формы и полный URL не передаются. Точная RAM вкладок неизвестна.

Проверяем подключение…



Сервис работает при запущенном Zapas. После явного подключения reconnect разрешён для этого профиля. «Отключить» прекращает reconnect.


Защита недавней активности: 10 минут для обоих действий. Active, pinned, audible, incognito, неизвестная активность и исключённые домены защищены. Выгрузка и закрытие могут потерять несохранённое состояние; звонки и формы нельзя надёжно определить через tabs API.
